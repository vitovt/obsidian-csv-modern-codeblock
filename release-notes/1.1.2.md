# CSV Modern Codeblock 1.1.2

This maintenance release improves toolbar usability in narrow Obsidian panes, fixes codeblock option defaults, and cleans up automated review warnings.

## Fixed

- Codeblock options on the opening fence now work reliably, including defaults such as `sort:true`, `filter:true`, `compact:true`, `zebra:true`, `high-table:true`, and `edit:true`.
- Option parsing now accepts both documented `key:value` syntax and existing `key=value` syntax, for example `title:"Folktales"` and `title=Grimm`.
- Toolbar buttons now choose the longest label mode that fits on one row, then fall back from full labels to short labels and finally compact icon labels on very narrow screens.
- Toolbar buttons no longer change width when toggled between inactive and active states.

## Changed

- Removed the `builtin-modules` build dependency and use Node's built-in module list instead.
- Replaced zebra-striping `!important` CSS rules with stronger selectors to better match Obsidian review guidance.

## Compatibility

- Existing CSV and TSV codeblocks continue to work.
- No data format changes are required.
- Release assets are still built automatically by GitHub Actions and include artifact attestations.
